# E-Commerce Sales & Customer Analytics

## Project Overview
This project analyzes e-commerce sales data using Python, SQL, and Power BI to identify sales trends, product performance, customer patterns, and order status insights.

## Tools & Technologies
- Python — data analysis and visualization
- Pandas — data manipulation
- Matplotlib — charts and graphs
- SQL — business queries and aggregations
- SQLite — database management
- Power BI — interactive dashboard

## Dataset
The project uses a sample e-commerce dataset containing 500 orders, customer information, product categories, sales values, payment methods, and order statuses.

## Key Performance Indicators
- Total Recorded Sales: ₹10,373,945
- Total Orders: 500
- Unique Customers: 15
- Average Order Value: ₹20,747.89
- Cancellation Rate: 21%

## Key Findings
- Electronics generated the highest recorded sales among categories.
- Laptops were the top-selling product by recorded sales value.
- April had the highest monthly sales, while July had the lowest.
- 105 out of 500 orders were marked as cancelled.

## Dashboard
An interactive Power BI dashboard presents KPI cards, monthly sales trends, product and category performance, order status analysis, and slicers for filtering results.

## Project Note
This project uses sample learning data. Recorded sales totals include rows marked as cancelled; therefore, they should not be interpreted as realized revenue without further validation.
